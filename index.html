Step-by-Step Integration Guide

1

Add the script

Florametric is one file with no dependencies. Load it once per page, anywhere before the elements you use it with:

<!-- From this site (GitHub Pages) -->
<script src="https://shamsghani.github.io/florametric/florametric.js"></script>

<!-- or from the jsDelivr CDN -->
<script src="https://cdn.jsdelivr.net/gh/shamsghani/florametric@main/florametric.js"></script>

Using a bundler (Vite, webpack, Next.js)? Install it from GitHub and import it. TypeScript types are included:

npm install github:shamsghani/florametric

import Florametric from 'florametric';
2

Place an element

Pick the element that matches what you want. No JavaScript is needed: each one starts itself, sizes to its box and pauses while scrolled off-screen.

<!-- One plant -->
<florametric-plant type="rose"></florametric-plant>

<!-- A row of plants -->
<florametric-garden species="sunflower,iris,tulip" count="6"></florametric-garden>

<!-- A meadow that grows in real time from a start date -->
<florametric-meadow start-time="2026-11-15" speed="7d"></florametric-meadow>
3

Size and style it

Elements are ordinary boxes: give them a width and height with CSS. Defaults are 280×380 px for a plant and 100%×360 px for gardens and meadows. To sit on your own background, use background="transparent". On light pages, also turn the glow off.

<florametric-plant type="tulip" background="transparent" glow="false"
  style="width: 100%; height: 320px;"></florametric-plant>
4

Switch traits on or off

Every trait is an attribute (kebab-case) and a JavaScript option (camelCase). Start from a preset and override what you need:

<!-- Static plants: no growth, no wind, no interaction -->
<florametric-garden preset="static" species="rose,tulip" count="4"></florametric-garden>

<!-- A still image: draws one frame, then no animation loop at all -->
<florametric-plant type="tulip" preset="static" animate="false"></florametric-plant>

<!-- Living, but flowers never wilt and nothing reseeds -->
<florametric-garden flower-cycles="false" reproduction="false"></florametric-garden>

<!-- Pure upright ASCII, no glow -->
<florametric-plant type="iris" preset="classic"></florametric-plant>

Presets: static (still life; add animate="false" to stop the loop too) · calm (gentle, no particles or reseeding) · classic (upright ASCII, no glow) · minimal (no grass or soil, transparent). The full list is in the options reference below.

5

Control it from JavaScript (optional)

Attributes can be changed at any time, and the plant reacts immediately. For full control, use the garden behind each element, or create one directly:

const el = document.querySelector('florametric-garden');
el.setAttribute('wind', '0');          // live toggle
el.garden.set({ glow: false, rotation: false });

// Or without an element (a selector, canvas or container)
const garden = Florametric.garden('#hero', {
  plants: ['sunflower', { type: 'rose', x: 0.7, age: 2 }],
  preset: 'calm'
});
garden.on('germinate', (plant, x) => console.log('new', plant.type, 'at', x));

// A still image: draws once, no animation loop
Florametric.render('#card', { type: 'tulip', background: 'transparent' });
6

Frameworks

Custom elements work in every framework. Load the script once (or import 'florametric') and use the tag:

// React
import 'florametric';
export const Flower = () => <florametric-plant type="rose" preset="calm" />;

// Vue / Svelte / Astro templates
<florametric-garden species="iris,tulip" count="5" reproduction="false" />

// React, with full control
useEffect(() => {
  const garden = Florametric.garden(ref.current, { preset: 'calm' });
  return () => garden.destroy();
}, []);

For server-side rendering, render the tag only in the browser. Gardens need a canvas, so with a framework that renders on the server, create them inside an effect or onMount.

7

Options reference

Defaults come from Florametric.defaults. Every option works as an attribute, in Florametric.garden(target, options) and in garden.set(options).

Troubleshooting

  • Nothing shows: the element or container has no height. Give it one with CSS.
  • Washed-out colours on a light page: set glow="false". The glow brightens what is behind it.
  • Many embeds on one page: use preset="static" or Florametric.render() for still plants, or fps="30" to cap the frame rate. Off-screen embeds already pause themselves.
  • Plants should not change between visits: set a seed. A meadow with a fixed start-time is the same for every visitor at the same moment.
  • Motion sensitivity: visitors with “reduce motion” turned on get gentle, slow wind automatically. Force it either way with reduced-motion.
  • Terminal or README output: Florametric.generateString({ type: 'rose' }) returns plain-text ASCII art (Node or browser).
