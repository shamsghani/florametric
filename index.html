How to Add ASCII Plants to Your Projects

Zero dependencies. Runs in any browser, blog, GitHub README, or terminal CLI.

Option 1: Drop-In Web Component (Zero JavaScript Needed)

Drop the script into your <head> and use the custom element anywhere in your HTML:

<!-- 1. Include the standalone library -->
<script src="https://shamsghani.github.io/florametric/florametric.js"></script>

<!-- 2. Embed an animated, cursor-reactive flower -->
<florametric-plant type="sunflower" age="1.0" bloom="1.0" interactive></florametric-plant>
<florametric-plant type="hibiscus" palette="botanical"></florametric-plant>
<florametric-plant type="iris" height="400"></florametric-plant>

Option 2: Vanilla JavaScript API (Custom Canvas or Garden)

Create an interactive garden or single plant programmatically:

import { AsciiPlant, AsciiGarden } from './florametric.js';

// Create multi-plant interactive garden
const garden = new AsciiGarden('#my-canvas', { wind: 0.7, palette: 'botanical' });
garden.addPlant(200, { type: 'sunflower', age: 1.0 });
garden.addPlant(400, { type: 'hibiscus', age: 0.8 });
garden.start(); // 60 FPS wind & cursor tracking

Option 3: Static ASCII Text Generator (For READMEs & Terminal CLIs)

Generate pure text strings with no DOM or canvas needed:

const textArt = Florametric.generateString({
  type: 'sunflower',
  age: 1.0,
  bloom: 1.0
});
console.log(textArt);
